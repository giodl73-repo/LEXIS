# Script and Reconstruction Caution Module

Status: planned, not executed.

This module plans research for the higher-risk parts of LEXIS: script lanes,
transliteration, reconstructed roots, sound-change uncertainty, and
non-Indo-European morphology.

No paper in this module is written yet. No script source, reconstructed form,
root-pattern fixture, graph output, or chronicle claim is promoted by these
plans.

## Module Questions

- How should LEXIS keep script form, glyph shape, transliteration, and sound
  value separate?
- What uncertainty labels are needed before reconstructed roots can appear in
  fixtures or chronicles?
- What graph shape would make a Greek alphabet lane useful without implying a
  universal writing-system taxonomy?
- Does a Semitic root-pattern slice require new entities or edge kinds?

## Module Exit Criteria

This module can close only when:

1. paper plans are reviewed,
2. papers are written with source pointers and source limits,
3. accepted findings update script/reconstruction specs or explicitly confirm
   no change,
4. source-custody and fixture blockers are updated,
5. L-1 through L-8 review records remaining blockers.
