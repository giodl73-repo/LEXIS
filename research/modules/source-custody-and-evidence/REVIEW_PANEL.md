# Review Panel: Source Custody and Evidence

Status: planned.

## Required Review Lanes

| Role | Review responsibility |
|---|---|
| L-1 Language Historian | Check historical scope and avoid broad lineage claims from source availability. |
| L-2 Etymology Reviewer | Check whether source families can support relationship claims without proving them by implication. |
| L-3 Phonology Reviewer | Check whether sound/pronunciation sources are required or explicitly deferred. |
| L-4 Script Systems Reviewer | Check whether script/orthography source posture is needed for the slice. |
| L-5 Source Custody Reviewer | Decide rights, redistribution, pointer-only, and blocked postures. |
| L-6 Graph Systems Reviewer | Check whether source posture can survive graph output later. |
| L-7 Product Chronicle Reviewer | Check whether source-limit wording can be explained to readers. |
| L-8 Software Assurance Reviewer | Check traceability to decisions, fixtures, diagnostics, and blockers. |

## Review Rule

Paper plans can be accepted as planning input. Paper findings cannot change
requirements, source decisions, fixtures, or work packages until the paper is
written and the module review records a DCR or explicit disposition.
