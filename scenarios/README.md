# LEXIS Scenarios

Status: planned, not executed.

Scenarios connect draft-reviewed specs to future validation workflows. They are
not fixtures, tests, source-custody decisions, graph outputs, chronicles, or
publication claims.

## Scenario Index

| Scenario | Purpose | Status |
|---|---|---|
| `language-history/word-root-slice` | Prove a bounded word/root family path from source pointers through chronicle review. | planned |
| `language-history/borrowing-vs-descent` | Prove descent, cognacy, borrowing, calque, and unknown/rejected claims stay distinct. | planned |
| `language-history/source-limited-claim` | Prove source-limited claims cannot become overconfident graph or chronicle output. | planned |
| `language-history/rline-preservation` | Prove graph/RLINE output preserves LEXIS labels and source posture. | planned |

## Promotion Rule

A scenario can become validation evidence only when:

1. source-custody posture is accepted where sources are involved,
2. positive and negative paths have expected outcomes,
3. diagnostic families are allocated,
4. fixture candidates are named but not silently promoted,
5. findings are reviewed by L-1 through L-8,
6. VTRACE evidence and validation rows are updated.
