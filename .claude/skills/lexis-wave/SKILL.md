# LEXIS Wave

Use this skill to create or update LEXIS waves.

## Wave requirements

- Start from `context/waves/PHASES.md` and the active wave.
- Advance one VTRACE deliverable at a time unless the user explicitly requests a
  rescue pass.
- Identify affected docs, future crates, source families, and downstream
  consumers.
- Include validation expectations for every pulse.
- Record linguistic, source-custody, graph, and product non-goals.
- Keep language semantics in LEXIS and graph mechanics in RLINE.
